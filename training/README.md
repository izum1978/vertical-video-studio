# 🚀 Обучение и запуск локальной нейросети Qwen 2.5 для Vertical Video Studio

В проект интегрирован провайдер **Qwen Local (Ollama / LM Studio / vLLM)**. Теперь генерация сценариев может работать **полностью автономно и бесплатно** на вашей видеокарте, без зависимости от OpenAI, Claude или Google Gemini.

---

## ⚡ Часть 1. Быстрый запуск базовой модели Qwen 2.5 (за 3 минуты)

Если вы хотите начать генерировать ролики через локальную модель прямо сейчас:

1. **Скачайте и установите Ollama:**
   👉 [https://ollama.com/download](https://ollama.com/download) (Windows / Mac / Linux).

2. **Запустите модель в командной строке:**
   ```bash
   # Рекомендуется для видеокарт с 8-12 ГБ VRAM (быстрая и качественная):
   ollama run qwen2.5:14b

   # Либо более легкая версия для видеокарт с 6-8 ГБ VRAM:
   ollama run qwen2.5:7b
   ```

3. **Запустите Vertical Video Studio:**
   - В веб-интерфейсе в блоке **«AI-генератор сценария»** выберите **🦙 Qwen Local**.
   - Нажмите **Сгенерировать видео**. Бэкенд автоматически подключится к `http://localhost:11434/v1` и сгенерирует сценарий с вирусной разметкой.

*(Если вы используете LM Studio вместо Ollama — запустите локальный сервер в LM Studio на порту 1234 и укажите в `.env`: `OLLAMA_BASE_URL=http://localhost:1234/v1`).*

---

## 🎭 Часть 2. Дуэт нейросетей: Сценарист-Режиссёр + Оператор-Постановщик

В студии работает архитектура из двух специализированных локальных моделей:
1. **Режиссёр и Сценарист (`qwen2.5-director:latest`)**:
   - Базовая модель: `qwen2.5:7b`.
   - Задача: хуки первых 3 секунд, драматургия, темпоритм, расстановка смысловых акцентов (`*слово*`, `!слово!`), звуковые маркеры `[sfx]`, вирусные клиффхэнгеры в Telegram.
   - Обучающий датасет: `training/dataset_viral_shorts.jsonl` (17 вирусных историй).
   - Модель Ollama: `training/Modelfile.director`.

2. **Оператор и Постановщик (`qwen2.5-cinematographer:latest`)**:
   - Базовая модель: `qwen2.5-coder:7b`.
   - Задача: единый визуальный паспорт (Visual Continuity Bible: палитра, атмосфера, свет, оптика) и хореография планов (`wide` -> `medium_pov` -> `extreme_close_up` -> `dutch_angle` -> `overhead`).
   - Обучающий датасет: `training/dataset_cinematographer.jsonl` (15 детальных операторских раскадровок).
   - Модель Ollama: `training/Modelfile.cinematographer`.

## ⚡ Часть 4. Способы обучения

### Вариант А. Google Colab (Бесплатно, в 1 клик на GPU T4)
Откройте ноутбук **`training/Fine_Tune_Qwen_Duo_Colab.ipynb`** в Google Colab:
- За 15 минут обучает обе модели через 4-bit LoRA (Unsloth).
- Сохраняет веса адаптеров и экспортирует GGUF для Ollama.

### Вариант Б. Локальный скрипт на ПК
```bash
python training/train_both_models.py --target all
```
*(Параметры: `--target director`, `--target cinematographer` или `--target all`).*

После обучения обе модели автоматически готовы к работе в Vertical Video Studio!
