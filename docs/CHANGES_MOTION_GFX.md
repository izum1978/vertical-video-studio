# Изменения: движок motion graphics (стиль референсов)

## Новое
| Файл | Что делает |
|---|---|
| `backend/app/motion_gfx/theme.py` | палитра, шрифты, холст с примитивами в координатах 1080x1920, кэш статичных фонов в 2x |
| `backend/app/motion_gfx/scenes_night.py` | 11 сцен ночной истории: посёлок, радио, сосед у забора, звук с кругами, лестница, вода в ванне, манометр, трасса, карта, дом со светом, иконки-подсказки |
| `backend/app/motion_gfx/scenes_generic.py` | 13 универсальных сцен: крупный текст, цифра-счётчик, чек-лист, хронология, сравнение, цитата, телефон, терминал, шаги, карточки, город, офис, финальная карточка |
| `backend/app/motion_gfx/overlays.py` | HUD (время и статус), карточка главы с бледной цифрой, плашка персонажа, стикеры |
| `backend/app/motion_gfx/engine.py` | планировщик (карточки глав, плашки, метка «НОЧЬ N», часы HUD, финальная карточка) и рендер через ffmpeg |
| `backend/app/providers/motion_gfx.py` | провайдер визуала `motion_gfx` |
| `tests/test_motion_gfx.py` | 12 тестов движка |

## Изменено
- `providers/__init__.py`: `motion_gfx` зарегистрирован; `vector_2d`, `cartoon`, `reference`, `motion` теперь ведут в него (раньше `vector_2d` и `cartoon` вели в AI-видеодиффузию, потому что прежний 2D-движок был удалён).
- `pipeline.py`: режим по умолчанию `motion_gfx`; для него пропускается вызов оператора, стиль субтитров `ref`, без полоски прогресса, чистый видеофильтр и 30 fps.
- `render.py`: стиль субтитров `ref` (фразы по 1-4 слова, будущие слова приглушены, акценты жёлтые и красные), параметры `fps` и `clean` у `render()`.
- `scene_resolver.py`: новые сцены в `SCENE_RENDERERS`, список для LLM `SCENE_CHOICES`, подсказки `SCENE_HINTS`, правила слов для сюжетных жанров, ротация `HORROR_ROTATION`.
- `director_llm.py`: схема и промпт режиссёра знают новые сцены; необязательные поля `items` и `overlays`.
- `director.py`: шаблонная раскадровка (запасная) не ставит сцены и подписи не по теме: сцену выбирает резолвер по смыслу текста.
- `main.py`, `frontend/src/App.jsx`: режим «Motion graphics» и стиль субтитров «Как в референсе» по умолчанию.
- `training/build_director_dataset.py`: сохраняет необязательные поля `items` и `overlays`.
- `.env.example`, `README.md`: переменные `MOTION_WIDTH`, `MOTION_FPS`, `MOTION_FONT`, описание режима.

## Удалён
- `tests/test_visuals.py`: проверял прежний `Vector2DVisual`, которого в проекте уже не было.

## Не менялось
`ai_video`, `ai_scenes`, `ai_engine/`, озвучка, SFX, озвучка таймкодов (см. раздел «Что дальше» в ответе).

- `engine.py`: сцены `generated` и `custom`, камера, запасная текстовая сцена, если художник ничего не нарисовал.
- `scene_resolver.py`, `director_llm.py`: `scene_type: custom` и поле `visual` (что нарисовать).
- `pipeline.py`, `main.py`, `frontend/src/App.jsx`: параметр `scene_gen` (auto, all, heuristic, off), статистика в `meta.json`.
- `director.py`: шаблонная раскадровка теперь почти целиком из motion-битов, чтобы художнику было что рисовать.

# Версия 3: критик композиции и обучение художника сцен

- `motion_gfx/designer.py`: геометрический критик (`quality_errors`: наложения, выход за кадр, мелкие и однотипные детали), `relevance` (доля предметов фразы в сцене), офлайн-художник расталкивает налезающие детали (`_declutter`).
- `motion_gfx/scene_dsl.py`: `to_compact`, компактный устойчивый формат сцены для датасета и кэша.
- `training/build_scene_dataset.py`, `training/eval_scene.py`, `training/scene_sentences.txt` (88 стартовых фраз): сборка датасета сцен из сильной модели с фильтрами и оценка моделей.
- `tests/test_scene_training.py`: 8 тестов. Всего в проекте 62 теста.

# Версия 4: настоящие таймкоды озвучки и позы персонажа

- `providers/tts.py`:
  - **Edge**: просит у сервиса события по словам (`boundary="WordBoundary"`, на старой версии библиотеки работает без параметра) и возвращает в слова знаки препинания из текста (`timing.restore_punctuation`), чтобы субтитры «ref» рвали фразы по запятым и точкам; времена остаются реальными.
  - **ElevenLabs**: запрос `with-timestamps`, слова из посимвольного выравнивания (`timing.alignment_to_words`); при ошибке обычный синтез и оценка.
  - **OpenAI**: оценка с паузами на знаках препинания вместо равномерных весов (сервис таймкодов не отдаёт).
- `motion_gfx/props_world.py`: позы человека `person_walk`, `person_run`, `person_wave` (анимированные) и `person_sit`; всего 62 детали.
- `motion_gfx/lexicon.py`, `designer.py`: глаголы «бежит, идёт, сидит, машет» выбирают нужную позу, обычный человек в этом случае не дублируется.
- Тесты: `tests/test_tts_timing.py` (5, сеть подменена), дополнены `test_timing.py` и `test_scene_designer.py`. Всего 70 тестов.

Известное ограничение: очистка текста перед озвучкой вырезает `!` (это разметка акцентов), поэтому восклицательный знак не рвёт фразу субтитров.
