1. Резюме
Архитектура у проекта верная: режиссёр с белым списком и валидатором, оператор, шаблонная раскадровка на случай сбоя, локальная Qwen через Ollama, скрипты LoRA-обучения. Но сейчас обучение и пайплайн почти не влияют на результат: часть работы Qwen молча перекрывается или выбрасывается, а дообученная модель, скорее всего, вообще не подключена.
Что именно не так (коротко)
Обучение: 17 и 15 примеров вместо сотен, около 56–64 эпох заучивания; формат обучения не совпадает с боевым запросом; дообученные веса не экспортируются в Ollama.
Пайплайн: подстроки в тексте перебивают выбор режиссёра; режиссёр видит только первые 80 слов; ошибки глотаются молча; нет повторной попытки, не задан размер контекста.
Данные для режиссёра: «пословные таймкоды» озвучки оценочные, а датасет по сюжету повторяет присланный референс.
Ответ на вопрос «что делаем первым»
Сначала патч пайплайна, потом сборщик датасета. Причина: запрос режиссёра при обучении и в бою должен собираться одной и той же функцией, а эта функция (build_user_prompt) появляется именно в патче. Кроме того, без логов и метрик нельзя понять, дало ли обучение пользу. Порядок: Ф0–Ф4 (около 3 рабочих дней) → Ф5 (таймкоды) → Ф6 (датасет) → Ф7 (обучение) → Ф8 (оценка).

2. Как устроен проект сейчас
По коду архива. Пайплайн идёт четырьмя стадиями, локальная Qwen участвует в трёх местах.
Тема -> [Сценарист] -> script.json (title, hook, script, scenes)
     -> [TTS] -> voice.mp3 + voice.words.json (таймкоды слов)
     -> [Режиссёр] -> beats (mode, scene_type, title, subtitle)   <- Qwen
     -> [Оператор] -> prompt/camera/continuity для AI-картинок    <- Qwen (coder)
     -> [Визуал] ai_scenes (картинки)  ИЛИ  vector_2d (16 PIL-рендереров)
     -> [Микс + SFX + субтитры + рендер ffmpeg] -> mp4 + meta.json

4. Подробно о каждой проблеме
T-01. Слишком мало обучающих данных
Что происходит: В датасетах 17 примеров (режиссёр, сценарии) и 15 (оператор). Скрипты обучения задают max_steps=120 при батче 2 и накоплении 4, то есть 8 примеров на шаг.
Проверка: 120 × 8 / 17 = около 56 эпох, 120 × 8 / 15 = 64 эпохи. Модель заучивает примеры наизусть.
Последствие: На новых темах модель либо повторяет заученные фразы, либо ломает формат. Метрики «обучение прошло» ничего не говорят о качестве.
Исправление: Ф6: 300–1000 разнообразных пар, собранных вашим же пайплайном; Ф7: 2–3 эпохи, валидация, ранняя остановка.
T-02. Формат обучения не совпадает с форматом использования
Что происходит: Датасет режиссёра учит модель выдавать сценарий (title, hook, script, scenes). Но director.py просит у той же модели раскадровку beats с другим системным промптом, а script.py вызывает ту же qwen2.5-director для сценария.
Последствие: Дообученная на сценариях модель с запросом на beats склонна вернуть сценарий. В ответе нет ключа beats, валидатор отклоняет его, включается шаблонная раскадровка, и никто этого не видит (см. B-03).
Исправление: Три задачи с отдельными форматами: сценарист, режиссёр, оператор (по желанию). Обучающий запрос режиссёра собирается той же функцией build_user_prompt и с тем же системным промптом, что и в бою (Ф3, Ф4, Ф6).
T-03. Дообучение не доходит до Ollama
Что происходит: train_both_models.py сохраняет только LoRA-веса, GGUF не экспортирует, переменная ollama_tag нигде не используется. В ноутбуке Colab экспорт в GGUF закомментирован. Modelfile.director начинается с FROM qwen2.5:7b, а Modelfile.cinematographer с FROM qwen2.5-coder:7b: это базовые модели с системным промптом.
Последствие: Если вы создавали модели командой ollama create из этих Modelfile, дообучения в них нет, хотя README пишет «автоматически готовы».
Как проверить: Команда ollama show qwen2.5-director --modelfile. Если в выводе FROM указывает на базовую модель и нет строки ADAPTER, это базовая Qwen с системным промптом.
Исправление: Ф7: train_director.py экспортирует GGUF, генерирует Modelfile с num_ctx и печатает команду ollama create.
T-04. Недочёты скрипта обучения
Что происходит: Loss считается и по системному промпту, и по запросу (нужен train_on_responses_only). Нет валидационной выборки и выбора лучшего чекпоинта. max_seq_length=2048 при строках датасета 3,4–4,4 тыс. символов (проверьте токены, иначе ответ обрезается). В новых версиях trl параметры dataset_text_field и max_seq_length переехали в SFTConfig; при TypeError причина в этом.
Исправление: Ф7: train_director.py подбирает имена параметров по сигнатурам установленных версий, проверяет длину в токенах, обучает только на ответах, сохраняет лучший чекпоинт по eval_loss.
T-05. Датасет повторяет сюжет референса и однотемен
Что происходит: Пример про дачу («потуши свет», «заблокируй лестницу», «что в доме напротив») почти один в один повторяет сюжет первого присланного вами ролика. Остальные примеры тоже в основном про хоррор-правила.
Последствие: Модель, обученная на этом, воспроизводит чужой сюжет, а на других жанрах ломается. Для продвижения это ещё и репутационный риск.
Исправление: Ф6: из референсов берётся структура и приёмы (хук, пронумерованные правила, клиффхэнгер), темы и сюжеты придумываются свои, жанры разнообразятся.
B-01. Подстроки перебивают выбор режиссёра
Что происходит: В Vector2DVisual.fetch ветки if/elif ищут ключевые слова как подстроки в тексте бита, и сработавший ключ выигрывает у scene_type, который выбрал режиссёр.
Проверка (запущено): Ложные срабатывания: «начать» → мессенджер (чат), «случай», «получилось», «лучше» → коридор с фонарём (луч), «столько» → свеча (стол), «кодекс» → киберчип (код), «шоколад» → кинетика (шок), «чипсы» → киберчип (чип).
Последствие: Результат работы Qwen случайно заменяется картинкой, которая подошла по буквам. Любые метрики качества режиссёра теряют смысл.
Исправление: Ф2: модуль scene_resolver.py. Приоритет: scene_type из белого списка, затем mode=chat, затем ключевые слова по границам слов, затем пресет и ротация. Причина выбора пишется в meta.json.
B-02. Режиссёр видит только 80 слов
Что происходит: В direct_storyboard берётся words_summary[:80], а сценарии в датасете содержат 90–126 слов (в среднем 104).
Проверка (запущено): В 17 из 17 примеров датасета сценарий длиннее 80 слов.
Последствие: Хвост ролика модель не видит, последние биты она «угадывает», валидатор растягивает последний бит до конца аудио.
Исправление: Ф3: режиссёр получает предложения с таймкодами (S1 [0.00-3.20] текст), покрывающие всё аудио. Это короче, чем пословный список, и точнее по границам.
B-03. Ошибки глотаются молча
Что происходит: В direct_storyboard стоит except Exception: pass. Нельзя понять, раскадровку сделала Qwen или шаблон. Нет повторной попытки, нет причины сбоя.
Исправление: Ф1 и Ф3: в meta.json пишется director.source (qwen, gemini, fallback, mock), модель, число попыток, список ошибок и задержка; в лог задания выводится строка с итогом; при сбое одна повторная попытка с текстом ошибок валидатора.
B-04. Нет ветки для провайдера claude
Что происходит: direct_storyboard знает провайдеров qwen, qwen_local, gemini, openai. Режиссёр берёт тот же провайдер, что выбран для сценария; при script=claude ветки нет, ответ пустой, всегда шаблон.
Исправление: Ф3: call_claude в director_llm.py; неизвестный провайдер даёт явную ошибку в журнале.
B-05. Таймауты, обрезка JSON, контекст Ollama
Что происходит: У режиссёра таймаут 60 с, у оператора 30 с; для 7B на слабой видеокарте этого может не хватить, и снова молчаливый фолбэк. У оператора max_tokens=1200 может обрезать JSON на длинных роликах. Размер контекста нигде не задан: через OpenAI-совместимый эндпоинт Ollama его не передать, а значение по умолчанию зависит от версии и может быть небольшим, тогда длинный запрос обрезается без предупреждения.
Исправление: Ф3: нативный API Ollama (/api/chat) с options.num_ctx=8192, num_predict=3000, таймаут 180 с (настраивается), параметр format со схемой JSON.
B-06. Оператор бесполезен в режиме vector_2d
Что происходит: Оператор пишет англоязычные промпты для генератора картинок. Векторный движок выбирает сцену по scene_type и ищет русские подстроки, промпты для него шум. Вызов при этом тратит до 30 с.
Исправление: Ф4: оператор вызывается только для ai_scenes, auto и cartoon; для vector_2d поля camera_shot и camera_motion режиссёр пишет сам (они есть в схеме).
B-07. Валидатор не проверяет scene_type
Что происходит: validate_and_repair_storyboard пропускает любую строку в scene_type.
Исправление: Ф2: scene_type нормализуется по белому списку; неизвестное значение превращается в пустое, и сцену выберет resolve_scene по смыслу. Для строгой проверки до починки есть check_storyboard.
B-08. Таймкоды озвучки оценочные
Что происходит: В tts.py слова размазываются по длительности аудио пропорционально длине слова (weights = len(w)+2). Реальных границ слов и пауз на точках и запятых нет.
Последствие: Границы предложений, которые видит режиссёр, и тайминги субтитров плывут относительно голоса.
Исправление: Ф5: берутся реальные события границ из edge-tts (WordBoundary или SentenceBoundary), запасной вариант с весом пауз на знаках препинания. Если нужны точные слова, можно использовать выравнивание Whisper.
B-09. Умолчания и разночтение режима cartoon
Что происходит: В main.py и во фронтенде по умолчанию visuals=ai_scenes и script=gemini, поэтому векторный движок и локальная Qwen включаются только при явном выборе. В pipeline.py значение cartoon направляется в ai_scenes, а в реестре провайдеров cartoon это Vector2DVisual.
Исправление: Ф4: выбрать один основной режим (рекомендуется vector_2d как стабильный и офлайновый), привести значения cartoon и 2d_cartoon к одному смыслу, показать выбор в интерфейсе.
H-01. Гигиена репозитория
Что происходит: В архиве нет git; лежат девять тестовых mp3, папка scratch и чужие документы; .env включён в архив (ключи в нём пусты, но так делать не стоит); нет автотестов; README обещает «автоматическую готовность» обученных моделей.
Исправление: Ф11: git, .gitignore, .env.example, очистка архива, pytest, правка README.
5. Принципы исправления
Сначала измерять, потом обучать. Любое улучшение должно быть видно в метриках (раздел 8).
Обучение равно использованию. Запрос и системный промпт при сборке датасета и в бою собираются одним кодом.
LLM выбирает, код рисует. Модель выдаёт значения из белых списков и слотов, а не координаты и не произвольный код.
Нет молчаливых сбоев. Каждый фолбэк виден в логе и в meta.json с причиной.
Одна роль, одна модель, один формат. Сценарист, режиссёр и оператор не делят адаптер.
Схема стабильна. Смена схемы раскадровки означает переобучение, поэтому новые компоненты сначала добавляются через промпт.
Данные свои. Из референсов берём приёмы, а не сюжеты и персонажей.

11. Референсы и стратегия
11.1. Второй ролик: что он показывает
Присланный разбор пайплайна канала описывает четыре этапа: идея, сценарий (ChatGPT), озвучка (ElevenLabs), визуал и монтаж. На последнем ИИ-агент с инструментами Python, Blender и FFmpeg собирает серию из 22 планов, синхронизирует их с голосом, добавляет движения камеры (наезды, панорамы, тряска), музыку и 13 типов атмосферных звуков. Вся раскадровка лежит в JSON с дорожками «видео, голос, камера, музыка». В кадрах готового ролика видна низкополигональная 3D-графика.
Вывод для проекта: идея «раскадровка JSON плюс детерминированный рендер» совпадает с вашей архитектурой. Ваш движок рисует 2D процедурно через PIL и ffmpeg; переходить на Blender сейчас не стоит. Сначала доведите текущую цепочку до измеримого качества, а 3D добавляйте позже как ещё один рендерер при той же схеме. Ролик к тому же рекламный: в нём сказано, что просмотры не гарантируют заработок.
11.2. Как закрепиться в нише
Главная угроза не конкуренты, а правила платформ. YouTube оценивает массовый шаблонный контент на уровне канала; TikTok допускает AI-контент при метке и подавляет неоригинальный. Делайте ролики разнообразными и ставьте метку AI там, где она нужна; перед запуском проверьте актуальные правила.
Пайплайн не защита: его повторят. Ров это свой IP (герои, мир, «ружья»), качество сюжета, узнаваемый стиль и данные об удержании вашей аудитории.
Человек в точках утверждения: план сезона, сценарий серии, первая реплика. 1–2 сильные серии в день лучше десяти средних.
Тест хуков: 2–3 варианта первых 3 секунд, метрики удержания (3-я секунда, средний досмотр, переход на следующую часть) возвращаются в промпты сценариста и в датасет.
Не копируйте героев и сюжеты конкурентов; берите структуру и приёмы.

def _rx(exact=(), prefix=()):
    """Короткие слова ищем по точным формам, длинные уникальные основы по префиксу.
    Границы слов (?<!\\w) и (?!\\w) работают с кириллицей."""
    parts = [re.escape(f) for f in exact] + [re.escape(p) + r"\w*" for p in prefix]
    return re.compile(r"(?<!\w)(?:" + "|".join(parts) + r")(?!\w)", re.IGNORECASE)

def _first_match(rules, text):
    for scene, rx in rules:
        m = rx.search(text)
        if m:
            return scene, f"keyword:{m.group(0).lower()}"
    return None
 
 
def resolve_scene(beat: dict, preset: str = "facts", index: int = 0) -> tuple[str, str]:
    """Возвращает (имя рендерера, причина). Причину пишем в meta для отладки."""
    st = normalize_scene_type(beat.get("scene_type"))
    if st:
        return st, "scene_type"
 
    mode = str(beat.get("mode") or "").lower()
    if mode == "chat":
        return "chat_messenger", "mode"
 
    # Англоязычный prompt оператора в поиск не берём: он только добавляет шум
    text = " ".join(str(beat.get(k) or "") for k in ("title", "subtitle", "text"))
 
    hit = _first_match(PRIMARY_RULES, text)
    if hit:
        return hit
    if preset in ("it", "tech"):
        return "cyber_chip", "preset"
    if preset == "horror_rules" or HORROR_WORDS.search(text):
        return HORROR_SCENES[index % len(HORROR_SCENES)], "horror_rotation"
    if mode == "dataviz":
        return "checklist_hud", "mode"
    hit = _first_match(SECONDARY_RULES, text)
    if hit:
        return hit
    if mode == "kinetic":
        return "kinetic_punch", "mode"
    return ROTATION[index % len(ROTATION)], "rotation"

# ---------- вход: предложения с таймкодами ----------
def clean_for_tts(script_text: str) -> str:
    s = re.sub(r"\[sfx:\s*\w+\]", "", script_text, flags=re.I)
    return re.sub(r"[*!]", "", s)
 
 
def split_sentences_with_timing(script_text: str, word_timestamps: list | None, total: float) -> list[dict]:
    sents = [s.strip() for s in re.split(r"(?<=[.?…])\s+", clean_for_tts(script_text)) if s.strip()]
    if not sents:
        sents = [clean_for_tts(script_text).strip() or "..."]
    counts = [max(1, len(s.split())) for s in sents]
    total_words = sum(counts)
    out, cum = [], 0
    words = [w for w in (word_timestamps or []) if isinstance(w, dict)]
    for s, c in zip(sents, counts):
        if words:
            i0 = min(len(words) - 1, round(cum * len(words) / total_words))
            i1 = min(len(words), max(i0 + 1, round((cum + c) * len(words) / total_words)))
            start = float(words[i0].get("start", 0.0))
            end = float(words[i1 - 1].get("end", start))
        else:
            start, end = total * cum / total_words, total * (cum + c) / total_words
        out.append({"text": s, "start": round(start, 2), "end": round(end, 2)})
        cum += c
    out[0]["start"] = 0.0
    out[-1]["end"] = round(total, 2)
    for a, b in zip(out, out[1:]):  # стыкуем без дыр
        a["end"] = b["start"] = round(max(a["start"], (a["end"] + b["start"]) / 2), 2)
    return out
 
 
def build_user_prompt(title: str, preset: str, total: float, sentences: list[dict]) -> str:
    """ЕДИНСТВЕННОЕ место, где собирается запрос режиссёра. Его же использует сборщик датасета."""
    lines = [f"S{i + 1} [{s['start']:.2f}-{s['end']:.2f}] {s['text']}" for i, s in enumerate(sentences)]
    return (
        f"Тема: {title}\nЖанр: {preset}\nДлительность аудио: {total:.2f} сек.\n"
        "Предложения с таймкодами:\n" + "\n".join(lines) +
        f"\n\nСформируй beats от 0.0 до {total:.2f} сек без дыр и наложений."
    )
 
 
# ---------- проверка ----------
def check_storyboard(sb, total: float) -> list[str]:
    """Строгая проверка. Пустой список = ответ годный. Мелкие дыры чинит validate_and_repair."""
    beats = sb.get("beats") if isinstance(sb, dict) else None
    if not isinstance(beats, list) or not beats:
        return ["в ответе нет непустого массива beats"]
    errs, prev_type, prev_end = [], None, 0.0
    for i, b in enumerate(beats):
        if not isinstance(b, dict):
            return [f"бит {i + 1} не объект"]
        st = normalize_scene_type(b.get("scene_type"))
        if b.get("mode") == "motion" and not st:
            errs.append(f"бит {i + 1}: scene_type '{b.get('scene_type')}' вне списка")
        try:
            s, e = float(b.get("start", prev_end)), float(b.get("end", 0))
        except (TypeError, ValueError):
            errs.append(f"бит {i + 1}: start/end не числа")
            continue
        if e - s > 6.0:
            errs.append(f"бит {i + 1}: длиннее 6 секунд")
        if abs(s - prev_end) > 0.5:
            errs.append(f"бит {i + 1}: дыра или наложение (начало {s}, ожидалось {prev_end})")
        if st and st == prev_type:
            errs.append(f"биты {i} и {i + 1}: одинаковый scene_type")
        prev_type, prev_end = st, e
    if abs(prev_end - total) > 1.5:
        errs.append(f"раскадровка заканчивается на {prev_end}, а аудио {total:.1f} сек")
    return errs
 
 
def parse_json_loose(raw: str) -> dict:
    raw = re.sub(r"^```(?:json)?|```$", "", (raw or "").strip(), flags=re.M).strip()
    try:
        return json.loads(raw)
    except json.JSONDecodeError:
        m = re.search(r"\{.*\}", raw, flags=re.S)  # JSON внутри лишнего текста
        if not m:
            raise
        return json.loads(m.group(0))

def _ollama_native_base() -> str:
    base = env("OLLAMA_BASE_URL", "http://localhost:11434/v1").rstrip("/")
    return base[:-3] if base.endswith("/v1") else base
 
 
def call_ollama(model: str, system: str, user: str, schema: dict | None, timeout: float) -> str:
    import httpx
    if env("OLLAMA_API", "native") == "openai":  # LM Studio / vLLM
        r = httpx.post(
            env("OLLAMA_BASE_URL", "http://localhost:11434/v1").rstrip("/") + "/chat/completions",
            headers={"Authorization": f"Bearer {env('OLLAMA_API_KEY', 'ollama')}"},
            json={"model": model, "temperature": 0.3,
                  "messages": [{"role": "system", "content": system}, {"role": "user", "content": user}],
                  "response_format": {"type": "json_object"}},
            timeout=timeout)
        r.raise_for_status()
        return r.json()["choices"][0]["message"]["content"]
    r = httpx.post(
        _ollama_native_base() + "/api/chat",
        json={"model": model, "stream": False,
              "messages": [{"role": "system", "content": system}, {"role": "user", "content": user}],
              "format": schema or "json",
              "options": {"temperature": 0.3,
                          "num_ctx": int(env("OLLAMA_NUM_CTX", "8192")),
                          "num_predict": int(env("OLLAMA_NUM_PREDICT", "3000"))}},
        timeout=timeout)
    r.raise_for_status()
    return r.json()["message"]["content"]
 
 
def call_gemini(model: str, system: str, user: str, schema, timeout: float) -> str:
    import httpx
    key = env("GEMINI_API_KEY")
    url = f"https://generativelanguage.googleapis.com/v1beta/models/{model}:generateContent?key={key}"
    r = httpx.post(url, json={"contents": [{"role": "user", "parts": [{"text": f"{system}\n\n{user}"}]}],
                              "generationConfig": {"response_mime_type": "application/json"}}, timeout=timeout)
    r.raise_for_status()
    return r.json()["candidates"][0]["content"]["parts"][0]["text"]

                   json={"model": model, "max_tokens": 3000, "temperature": 0.3, "system": system,

    r.raise_for_status()
    return "".join(b.get("text", "") for b in r.json()["content"] if b.get("type") == "text")
 
 
def _models_for(provider: str) -> tuple:
    if provider in ("qwen", "qwen_local"):
        names = [env("OLLAMA_DIRECTOR_MODEL"), env("OLLAMA_MODEL", "qwen2.5:7b")]
        return call_ollama, [n for n in dict.fromkeys(names) if n]
    if provider == "gemini":
        return call_gemini, [env("GEMINI_MODEL", "gemini-2.5-flash")]
    if provider == "openai":
        return call_openai, [env("OPENAI_MODEL", "gpt-4o-mini")]
    if provider in ("claude", "anthropic"):
        return call_claude, [env("ANTHROPIC_MODEL", "claude-sonnet-4-6")]
    raise ValueError(f"Режиссёр не поддерживает провайдера '{provider}'")
 
 
def call_llm(provider: str, system: str, user: str, schema: dict | None) -> tuple[str, str]:
    """Возвращает (текст ответа, имя модели, которая ответила)."""
    fn, models = _models_for(provider)
    timeout = float(env("DIRECTOR_TIMEOUT", "180"))
    last = None
    for model in models:
        try:
            return fn(model, system, user, schema, timeout), model
        except Exception as e:  # noqa: BLE001 пробуем следующую модель, ошибку запоминаем
            last = e
    raise RuntimeError(f"{provider}: {last}")
 
 
# ---------- главная функция ----------
def direct_storyboard_v2(script_data, word_timestamps, total_duration, preset="facts",
                         provider_name="qwen", mock=False, log=print,
                         fallback=None, repair=None, llm=call_llm) -> dict:
    """fallback и repair передаются из director.py (create_fallback_storyboard и
    validate_and_repair_storyboard); llm можно подменить в тестах."""
    script_text, title = script_data.get("script", ""), script_data.get("title", "")
    info = {"source": None, "model": None, "attempts": 0, "errors": [], "latency_s": 0.0}
 
    def finish(sb, source):
        info["source"] = source
        sb.setdefault("meta", {})["director"] = info
        return sb
 
    if mock:
        sb = fallback(script_text, total_duration, preset=preset, title=title)
        return finish(repair(sb, total_duration)[2], "mock")
 
    sentences = split_sentences_with_timing(script_text, word_timestamps, total_duration)
    user_prompt = build_user_prompt(title, preset, total_duration, sentences)
    feedback, t0 = "", time.time()
    for attempt in range(1, MAX_ATTEMPTS + 1):
        info["attempts"] = attempt
        try:
            raw, model = llm(provider_name, DIRECTOR_SYSTEM_PROMPT, user_prompt + feedback, STORYBOARD_SCHEMA)
            info["model"] = model
            parsed = parse_json_loose(raw)
            errs = check_storyboard(parsed, total_duration)
            if errs:
                info["errors"] += [f"попытка {attempt}: {e}" for e in errs]
                if attempt < MAX_ATTEMPTS:
                    feedback = ("\n\nПредыдущий ответ содержал ошибки: " + "; ".join(errs[:5]) +
                                ". Исправь и верни полный JSON.")
                    continue
            ok, msg, repaired = repair(parsed, total_duration)
            if ok:
                info["latency_s"] = round(time.time() - t0, 1)
                log(f"Режиссёр: {provider_name}/{model}, попыток {attempt}, замечаний {len(errs)}")
                return finish(repaired, provider_name)
            info["errors"].append(f"попытка {attempt}: {msg}")
        except Exception as e:  # noqa: BLE001
            info["errors"].append(f"попытка {attempt}: {type(e).__name__}: {e}")
    info["latency_s"] = round(time.time() - t0, 1)
    log(f"⚠ Режиссёр: LLM не дала валидную раскадровку, включён шаблон. Причины: {'; '.join(info['errors'][-3:])}")
    sb = fallback(script_text, total_duration, preset=preset, title=title)
    return finish(repair(sb, total_duration)[2], "fallback")

Новый файл. Проверен юнит-тестами (Приложение И). Реальные границы предложений и запасной расчёт с паузами.
"""Таймкоды слов: реальные границы от edge-tts, запасной вариант с паузами на знаках препинания."""
 
 
def marks_to_words(marks: list[dict]) -> list[dict]:
    """marks: события edge-tts [{word,start,end,kind}] (kind: WordBoundary | SentenceBoundary).
    Границы предложений реальные; внутри предложения слова делятся по длине."""
    words = []
    for m in marks:
        if m.get("kind") == "SentenceBoundary":
            ws = str(m["word"]).split()
            if not ws:
                continue
            weights = [len(w) + 2 for w in ws]
            t, span = m["start"], m["end"] - m["start"]
            for w, wt in zip(ws, weights):
                d = span * wt / sum(weights)
                words.append({"word": w, "start": round(t, 3), "end": round(t + d, 3)})
                t += d
        else:
            words.append({"word": m["word"], "start": m["start"], "end": m["end"]})
    return words
 
 
def proportional_timing(text: str, duration: float) -> list[dict]:
    """Запасной вариант без событий: вес слова = длина + пауза после знака препинания."""
    words = text.split()
    if not words or duration <= 0:
        return []
    def weight(w):
        extra = 6 if w.endswith((".", "?", "!", "…")) else 3 if w.endswith((",", ";", ":", "-")) else 0
        return len(w.strip(".,;:!?…-")) + 2 + extra
    weights = [weight(w) for w in words]
    total, t, out = sum(weights), 0.0, []
    for w, wt in zip(words, weights):
        d = duration * wt / total
        out.append({"word": w, "start": round(t, 3), "end": round(t + d, 3)})
        t += d
    return out

               "camera_shot", "camera_motion"]

def quality_errors(beats: list[dict], preset: str) -> list[str]:
    """Фильтр качества СВЕРХ базовой проверки: плохие примеры в датасет не попадают."""
    errs = []
    if not 4 <= len(beats) <= 14:
        errs.append(f"число битов {len(beats)} вне диапазона 4-14")
    for b in beats:
        d = b["end"] - b["start"]
        if not 1.5 <= d <= 6.0:
            errs.append(f"бит {b['id']}: длительность {d:.1f} с")
        if len(str(b.get("title", "")).split()) > 3:
            errs.append(f"бит {b['id']}: title длиннее 3 слов")
        if not b.get("camera_shot") or not b.get("camera_motion"):
            errs.append(f"бит {b['id']}: нет camera_shot/camera_motion")
    types = [b["scene_type"] for b in beats if b["mode"] == "motion"]
    if len(beats) >= 6 and len(set(types)) < 3:
        errs.append("слишком мало разных scene_type")
    if preset == "horror_rules":
        share = len(types) / max(1, len(beats))
        if share < 0.8:
            errs.append(f"для horror_rules motion {share:.0%} (< 80%)")
        if any(t not in HORROR_SCENES for t in types):
            errs.append("в horror_rules попала не хоррор-сцена")
    return errs
 
 
def canonical_beats(parsed: dict, total: float) -> list[dict]:
    """Оставляем только поля схемы, нормализуем scene_type, склеиваем границы."""
    beats = []
    for i, b in enumerate(parsed["beats"]):
        row = {k: b.get(k) for k in BEAT_FIELDS}
        row["id"] = i + 1
        row["scene_type"] = normalize_scene_type(b.get("scene_type")) or ""
        row["start"], row["end"] = round(float(b["start"]), 2), round(float(b["end"]), 2)
        beats.append(row)
    beats[0]["start"], beats[-1]["end"] = 0.0, round(total, 2)
    for a, b in zip(beats, beats[1:]):
        b["start"] = a["end"]
    return beats
 
 
def split_of(key: str, val_share: float = 0.1) -> str:
    """Разделение train/val по ТЕМЕ (хэш), чтобы одна тема не попала в обе выборки."""
    h = int(hashlib.md5(key.encode("utf-8")).hexdigest(), 16) % 1000
    return "val" if h < val_share * 1000 else "train"
 
 
def build_record(topic, preset, script_fn, timing_fn, llm, max_attempts=3):
    """script_fn(topic, preset) -> dict(script,title); timing_fn(script_text) -> (words|None, total);
    llm(system, user) -> raw json str. Возвращает (record|None, причина_отказа|None)."""
    sc = script_fn(topic, preset)
    words, total = timing_fn(sc["script"])
    sents = split_sentences_with_timing(sc["script"], words, total)
    user = build_user_prompt(sc.get("title") or topic, preset, total, sents)
    feedback, last = "", []
    for _ in range(max_attempts):
        try:
            parsed = parse_json_loose(llm(DIRECTOR_SYSTEM_PROMPT, user + feedback))
        except Exception as e:  # noqa: BLE001
            last = [f"ответ не JSON: {e}"]
            continue
        errs = check_storyboard(parsed, total)
        if not errs:
            beats = canonical_beats(parsed, total)
            errs = quality_errors(beats, preset)
            if not errs:
                answer = json.dumps({"beats": beats}, ensure_ascii=False)
                return {"messages": [{"role": "system", "content": DIRECTOR_SYSTEM_PROMPT},
                                     {"role": "user", "content": user},
                                     {"role": "assistant", "content": answer}],
                        "meta": {"topic": topic, "preset": preset, "duration": total,
                                 "split": split_of(topic)}}, None
        last = errs
        feedback = "\n\nПредыдущий ответ не подошёл: " + "; ".join(errs[:5]) + ". Исправь и верни полный JSON."
    return None, "; ".join(last)

"""Дообучение режиссёра (Qwen2.5-7B-Instruct, QLoRA, Unsloth) + экспорт в GGUF для Ollama.
 
Отличия от train_both_models.py:
  * loss считается только на ответе ассистента (train_on_responses_only);
  * есть валидационная выборка, лучший чекпоинт сохраняется;
  * число эпох вместо фиксированных 120 шагов;
  * параметры SFTConfig/SFTTrainer подбираются по сигнатуре установленных версий trl/transformers;
  * в конце экспорт GGUF и готовый Modelfile с num_ctx.
 
Запуск: python training/train_director.py --epochs 3

def load_jsonl(path):

    return [{"messages": r["messages"]} for r in rows]   # meta обучению не нужна
 
 
def main():

    ap.add_argument("--model", default="unsloth/Qwen2.5-7B-Instruct-bnb-4bit")
    ap.add_argument("--train", default=str(HERE / "data" / "director_train.jsonl"))
    ap.add_argument("--val", default=str(HERE / "data" / "director_val.jsonl"))
    ap.add_argument("--out", default=str(HERE / "out_director"))
    ap.add_argument("--epochs", type=float, default=3)
    ap.add_argument("--lr", type=float, default=1e-4)
    ap.add_argument("--max-len", type=int, default=4096)
    ap.add_argument("--rank", type=int, default=16)
    ap.add_argument("--tag", default="qwen2.5-director-v1")
    a = ap.parse_args()
 
    from unsloth import FastLanguageModel
    from unsloth.chat_templates import train_on_responses_only
    from datasets import Dataset
    from trl import SFTConfig, SFTTrainer
    import torch
 
    model, tok = FastLanguageModel.from_pretrained(a.model, max_seq_length=a.max_len, load_in_4bit=True, dtype=None)
    model = FastLanguageModel.get_peft_model(
        model, r=a.rank, lora_alpha=a.rank * 2, lora_dropout=0, bias="none",
        target_modules=["q_proj", "k_proj", "v_proj", "o_proj", "gate_proj", "up_proj", "down_proj"],
        use_gradient_checkpointing="unsloth", random_state=42)
 
    def to_text(rows):
        return Dataset.from_list([{"text": tok.apply_chat_template(r["messages"], tokenize=False,
                                                                   add_generation_prompt=False)} for r in rows])
    train_rows, val_rows = load_jsonl(a.train), load_jsonl(a.val)
    train_ds, val_ds = to_text(train_rows), to_text(val_rows)
 
    # Проверка длины: примеры длиннее max-len обрежутся, и модель не увидит конец JSON
    lens = [len(tok(t["text"]).input_ids) for t in train_ds]

    if too_long:
        raise SystemExit("Есть примеры длиннее max-len: увеличьте --max-len или отфильтруйте датасет.")
 
    cfg_params = inspect.signature(SFTConfig.__init__).parameters

    print(f"\nГотово. Подключите модель в Ollama:\n  cd {a.out}\n  ollama create {a.tag} -f Modelfile\n"
          f"и пропишите в .env:  OLLAMA_DIRECTOR_MODEL={a.tag}")

"""Оценка режиссёра: сравнивает модели на отложенной выборке (director_val.jsonl).
 
  python training/eval_director.py --models qwen2.5:7b qwen2.5-director-v1 --limit 50
 
Метрики считаются теми же функциями, что и в бою (check_storyboard), плюс разнообразие.
"""
import argparse

from collections import Counter
from math import log2
from pathlib import Path

sys.path.insert(0, str(ROOT / "backend"))
from app.director_llm import STORYBOARD_SCHEMA, call_ollama, check_storyboard, parse_json_loose  # noqa: E402
from app.scene_resolver import SCENE_RENDERERS, normalize_scene_type  # noqa: E402
 
 
def score_one(raw: str, total: float) -> dict:
    m = {"json_ok": 0, "schema_ok": 0, "whitelist_ok": 0, "no_repeat": 0, "coverage_ok": 0, "entropy": 0.0}
    try:
        sb = parse_json_loose(raw)
        m["json_ok"] = 1
    except Exception:  # noqa: BLE001
        return m
    beats = sb.get("beats") if isinstance(sb, dict) else None
    if not isinstance(beats, list) or not beats:
        return m
    errs = check_storyboard(sb, total)
    m["schema_ok"] = int(not errs)
    m["whitelist_ok"] = int(all(normalize_scene_type(b.get("scene_type")) for b in beats if b.get("mode") == "motion"))
    types = [normalize_scene_type(b.get("scene_type")) for b in beats]
    m["no_repeat"] = int(all(a != b for a, b in zip(types, types[1:])))
    m["coverage_ok"] = int(not any("дыра" in e or "заканчивается" in e for e in errs))
    c = Counter(t for t in types if t)
    n = sum(c.values()) or 1
    m["entropy"] = round(-sum(v / n * log2(v / n) for v in c.values()), 2)
    return m
 
 
def evaluate(model: str, rows: list[dict], caller) -> dict:
    agg, t0 = Counter(), time.time()
    for r in rows:
        system, user = r["messages"][0]["content"], r["messages"][1]["content"]
        total = float(r["meta"]["duration"])
        try:
            raw = caller(model, system, user)
        except Exception:  # noqa: BLE001
            raw = ""
        for k, v in score_one(raw, total).items():
            agg[k] += v
    n = max(1, len(rows))
    out = {k: round(v / n, 3) for k, v in agg.items()}
    out["sec_per_sample"] = round((time.time() - t0) / n, 1)
    return out
 
 
def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("--val", default=str(ROOT / "training" / "data" / "director_val.jsonl"))
    ap.add_argument("--models", nargs="+", required=True)
    ap.add_argument("--limit", type=int, default=50)
    a = ap.parse_args()
    rows = [json.loads(l) for l in Path(a.val).read_text(encoding="utf-8").splitlines() if l.strip()][: a.limit]
    caller = lambda model, system, user: call_ollama(model, system, user, STORYBOARD_SCHEMA, 300)  # noqa: E731
    print(f"{'модель':32} json  схема whitelist без_повторов покрытие энтропия сек/пример")
    for m in a.models:
        r = evaluate(m, rows, caller)
        print(f"{m:32} {r['json_ok']:.2f}  {r['schema_ok']:.2f}  {r['whitelist_ok']:.2f}      {r['no_repeat']:.2f}"
              f"        {r['coverage_ok']:.2f}    {r['entropy']:.2f}     {r['sec_per_sample']}")
 
 
if __name__ == "__main__":
    main()

SCRIPT = ("Если ночью пропадёт связь, не выходи из дома. Правило первое: потуши свет и отойди от окон. "
          "Правило второе: заблокируй лестницу. Правило третье: не отвечай на голос из коридора. "
          "Что дальше, расскажу в следующей части.")
def script_fn(topic, preset): return {"script": SCRIPT, "title": topic}
def timing_fn(s): return mod.estimate_timing(s)
 
def sb(total, types=None, shots=True, n=6):
    types = types or ["window_stalker", "peephole_stalker", "door_breach", "corridor_flashlight", "candle_paranoia", "drag_void"]
    seg = total / n; beats = []
    for i in range(n):
        b = {"id": i + 1, "start": round(i * seg, 2), "end": round(total if i == n - 1 else (i + 1) * seg, 2),
             "text": "т", "mode": "motion", "scene_type": types[i % len(types)], "title": "ТИТУЛ", "subtitle": "ПОДПИСЬ"}
        if shots: b["camera_shot"], b["camera_motion"] = "wide", "zoom_in"
        beats.append(b)
    return {"beats": beats}
 
def test_good_record_is_canonical_and_matches_runtime_prompt():
    _, total = timing_fn(SCRIPT)
    rec, why = mod.build_record("Тема А", "horror_rules", script_fn, timing_fn, lambda s, u: json.dumps(sb(total)))
    assert rec and why is None
    system, user, assistant = [m["content"] for m in rec["messages"]]
    assert system == mod.DIRECTOR_SYSTEM_PROMPT
    assert "Предложения с таймкодами:" in user and "S5 [" in user
    data = json.loads(assistant)
    assert list(data) == ["beats"] and data["beats"][0]["start"] == 0.0 and data["beats"][-1]["end"] == total
    assert all(set(b) == set(mod.BEAT_FIELDS) for b in data["beats"])
    assert rec["meta"]["split"] in ("train", "val")
 
def test_bad_quality_is_rejected_after_retries():
    _, total = timing_fn(SCRIPT)
    calls = []
    def llm(s, u):
        calls.append(u); return json.dumps(sb(total, shots=False))   # нет camera_* -> отбраковка
    rec, why = mod.build_record("Тема Б", "horror_rules", script_fn, timing_fn, llm)
    assert rec is None and "camera_shot" in why and len(calls) == 3
    assert "не подошёл" in calls[1]
 
def test_retry_recovers():
    _, total = timing_fn(SCRIPT)
    seq = ["не json вообще", json.dumps(sb(total))]
    rec, why = mod.build_record("Тема В", "horror_rules", script_fn, timing_fn, lambda s, u: seq.pop(0))
    assert rec is not None
 
def test_horror_needs_horror_scenes():
    _, total = timing_fn(SCRIPT)
    bad = sb(total, types=["cyber_chip", "atomic_orbit", "dynamic_canvas", "kinetic_punch", "checklist_hud", "chat_messenger"])
    rec, why = mod.build_record("Тема Г", "horror_rules", script_fn, timing_fn, lambda s, u: json.dumps(bad))
    assert rec is None and "не хоррор-сцена" in why

def sb(total, types_):
    n = len(types_); seg = total / n
    return {"beats": [{"id": i + 1, "start": round(i * seg, 2), "end": round(total if i == n - 1 else (i + 1) * seg, 2),
                       "mode": "motion", "scene_type": t} for i, t in enumerate(types_)]}
 
def test_scoring():
    good = json.dumps(sb(20, ["window_stalker", "door_breach", "drag_void", "candle_paranoia"]))
    m = mod.score_one(good, 20.0)
    assert m["json_ok"] == m["schema_ok"] == m["whitelist_ok"] == m["no_repeat"] == m["coverage_ok"] == 1 and m["entropy"] == 2.0
    rep = mod.score_one(json.dumps(sb(20, ["window_stalker", "window_stalker", "drag_void", "candle_paranoia"])), 20.0)
    assert rep["no_repeat"] == 0 and rep["schema_ok"] == 0
    assert mod.score_one("мусор", 20.0)["json_ok"] == 0
    assert mod.score_one(json.dumps({"title": "x"}), 20.0)["schema_ok"] == 0
    wl = mod.score_one(json.dumps(sb(20, ["window_stalker", "zombie", "drag_void", "candle_paranoia"])), 20.0)
    assert wl["whitelist_ok"] == 0
 
def test_evaluate_aggregates():
    rows = [{"messages": [{"content": "s"}, {"content": "u"}], "meta": {"duration": 20.0}}] * 4
    outs = iter([json.dumps(sb(20, ["window_stalker", "door_breach", "drag_void", "candle_paranoia"]))] * 2 + ["мусор", "мусор"])
    r = mod.evaluate("m", rows, lambda *a: next(outs))
    assert r["json_ok"] == 0.5 and r["schema_ok"] == 0.5

import sys
from pathlib import Path
ROOT = Path(__file__).resolve().parents[1]
from app.timing import marks_to_words, proportional_timing
 
def test_sentence_marks_keep_real_pause():
    marks = [{"word": "Привет мир", "start": 0.0, "end": 1.0, "kind": "SentenceBoundary"},
             {"word": "Снова тишина", "start": 2.0, "end": 3.5, "kind": "SentenceBoundary"}]
    w = marks_to_words(marks)
    assert [x["word"] for x in w] == ["Привет", "мир", "Снова", "тишина"]
    assert w[1]["end"] == 1.0 and w[2]["start"] == 2.0          # пауза 1 с сохранена
    assert abs(w[-1]["end"] - 3.5) < 0.01
 
def test_word_marks_pass_through():
    w = marks_to_words([{"word": "да", "start": 0.1, "end": 0.3, "kind": "WordBoundary"}])
    assert w == [{"word": "да", "start": 0.1, "end": 0.3}]
 
def test_proportional_covers_duration_and_pauses_longer():
    w = proportional_timing("Свет погас. Он ждал, молча.", 10.0)
    assert abs(w[-1]["end"] - 10.0) < 0.01 and w[0]["start"] == 0.0
    plain = proportional_timing("Свет погас Он ждал молча", 10.0)
    assert (w[1]["end"] - w[1]["start"]) > (plain[1]["end"] - plain[1]["start"])  # слово перед точкой длиннее
    assert proportional_timing("", 5) == [] and proportional_timing("а", 0) == []
